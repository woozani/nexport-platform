# NEXPORT 용어 체계 (Terminology) — SSOT

**출처:** 전략 세션 핸드오프 D3 (`docs/strategy/nexport-session-handoff-260814.xml`, status=confirmed)
**성격:** 전 세션 공유 SSOT — 문서(docs/specs)·플랫폼(src)·랜딩(nexport-landing 리포) 3곳의 고객 대면 카피는 이 표를 기준으로 정합 유지
**커밋일:** 2026-08-14

---

## 원칙

1. **기술/내부 용어의 고객 노출 금지**
2. **영어 비유의 직역 금지** (예: backbone → "중심축" 같은 직역 사용 금지)
3. **위협 프레임 금지** — 혜택 청구 프레임으로 전환. 처벌 장치는 약관 후면에만 배치

---

## 용어표

| 내부 용어 | 고객 노출 용어 | 비고 |
|---|---|---|
| 자진 신고 할인 | **첫 수출 지원 신청** | 신청 시 매칭 성사비 우대 요율 + 첫 수출 실행 지원 패키지 |
| 성공 보수 / 커미션 | **매칭 성사비** | '커미션' 대면 사용 금지 |
| 언마스킹 | **바이어 정보 열람** | |
| 크레딧 | **크레딧** | 유지 확정 |
| BOL 모니터링/탐지 | **수출 동향 리포트** | 탐지 기능의 제품화 — 고객에게 유용한 기능이자 조용한 억제력 |
| progressive reveal | (노출 안 함) | 내부 설계 용어 |

---

## 적용 규칙

- 고객 대면 산출물(플랫폼 UI, 랜딩 카피, 이메일 템플릿, 계약서 전면부) 작성·수정 시 이 표의 "고객 노출 용어" 열만 사용
- 내부 문서(dev_spec XML, 운영정책, 세션 기록)에서는 내부 용어 사용 가능하되, 고객 노출 문구 인용 시 반드시 변환
- 관련 정비 항목: 생존전략 v1.1 F2 — §7.1 "증빙 제출 시 커미션 할인·감사권·위약벌" 전면 노출 → 이 용어 체계로 스윕
- 용어 추가·변경 시 이 파일을 먼저 갱신하고, 3곳(문서·플랫폼·랜딩) 정합을 같은 작업 단위에서 처리할 것
