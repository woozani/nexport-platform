## 2. 제품 모델 (v0.2 — 검색 없음)

- **월 N건 자동 추천 + 트래킹 + 영업보고서** 모델. 검색/리스트 브라우징 화면 없음 (스크래핑 방지)
- 플로우: 가입 → 프로필(서술형+박스) → 유사 바이어 5개 훅 → 추천 카드(마스킹) → AI 메일 → 플랫폼 발송 → 트래킹(D+7 팔로업/D+14 해제) → 회신 수신함 → **연락처 열람(응답 확인된 바이어만 크레딧 1 차감)** → 거래 단계(미팅→샘플→견적→계약, 수수료 연결) → 월간 보고서(오프-플랫폼 체크)
- 요금: **Founding Member 단일 무료(BEP 전) + 크레딧 + 매칭 성사비**. `PLAN_CONFIG` 설정 테이블 (req 4-1). 데이터 비판매·bulk export 없음
- 등급 GOLD~DEAD (COLD/DEAD는 UI 비노출), engagement score 정렬, append-only 열람 로그
