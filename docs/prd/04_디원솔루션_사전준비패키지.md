## 1. 사전 설문 예상 문항 — 선제 답변

**서비스 한 줄 정의**
> 한국 중소 제조사를 위한 AI 바이어 아웃리치 시스템. 필터링 → AI 맞춤 메일 생성 → 유저 검수·승인 → 대량 발송 → 회신 관리까지 단일 플로우.

**타겟 유저**
- Primary: 매출 50~200억 제조사 대표 (결제권자)
- User: 해외영업 담당 1~2인 (실사용자)
- 특성: 디지털 도구 활용 역량 낮음. Apollo/LinkedIn 미사용층. "구글링+엑셀+번역기" 현장.
- **디자인 함의: 뎁스 얕게, 전문용어 최소화, 한 화면 한 가지 일**

**벤치마크 / 반면교사**
- 직접 경쟁: LinkedIn Sales Navigator
- 반면교사: Apollo.io — "기능이 너무 많아 1%만 쓴다" (Jay 실사용)
- D1 포트폴리오 중 참고: **Pickome의 카드형 단계 프로세스 + 체크리스트 UX** → NEXPORT 발송 승인(책임 고지) 플로우에 유사 패턴 적용 가능

**플랫폼**: 반응형 WEB (데스크톱 우선, 태블릿 대응) / 모바일 앱 아님

**핵심 지표(디자인이 도와야 할 것)**: 발송까지 완료율, 회신 확인 재방문율

**제외 범위(디자인 불필요)**: DB 브라우징 시각화, 커뮤니티, 뉴스/시장동향 뷰, 매출 보장성 표현

## 5. 개발 미팅(②단계) 아젠다 — NEXPORT 질문 리스트

1. **초기 DB 임포트**: 구매 리스트 ~10,000건 스키마(CSV) 임포트 방식, 중복/무효 이메일 필터링
2. **메일 발송 인프라**: SendGrid/SES 등 선택, 발송 도메인 분리·워밍업, 일 발송량 제한, 스팸 평판 관리
3. **회신 수집**: 전용 수신 도메인 vs IMAP 연동, 스레드 매칭 방식
4. **AI 메일 생성**: LLM API 비용 구조, 생성 속도(N건 병렬), 프롬프트에 제품 프로필+바이어 정보 주입 구조
5. **회신 분류**: 규칙 기반 vs LLM 분류, 초기 정확도 기대치
6. **개발 범위/비용**: 디자인 600만원 외 개발 견적 범위, D1 개발팀 직접 수행 vs 별도 개발사
7. **Apollo DB 샘플 시연** (Jay 준비 — 액션 아이템 #3)
