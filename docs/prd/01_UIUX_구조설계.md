# NEXPORT UI/UX 개발 Structure & Foundation
**기준:** 2026-07-29 디원솔루션 미팅 결정사항 + 벙커샷 옵션 B− 포지셔닝
**목적:** 디원솔루션 디자인 착수 및 개발자 미팅의 기준 문서

---

## 1. 설계 원칙 (미팅에서 확정)

1. **단일 코어 플로우** — 컨택(아웃리치) 플로우 하나만 깔끔하게. 그 외 전부 보조.
2. **Apollo 반면교사** — 기능 최소화. "1%만 쓰는 기능"을 만들지 않는다. 뎁스 얕게.
3. **책임 소재는 유저에게** — AI 산출물은 반드시 유저가 전문 확인·수정·승인 후 발송.
4. **DB는 숨긴다** — 양질 DB 확보 전까지 DB 브라우징·시각화는 전면에 두지 않음.
5. **정보는 요약으로** — 기업 정보 3문단 → 1~2줄 요약. 읽게 하지 말고 판단하게 한다.

## 2. Information Architecture (목표 구조)

```
NEXPORT
├── [P0] 온보딩 — 회사·제품·인증 프로필 입력 (AI 메일의 원천 데이터)
├── [P0] 캠페인 (코어 플로우) ⭐
│   ├── 1. 타겟 필터링 (산업/지역/인증/규모)
│   ├── 2. 발송 리스트 확정 (자동 리스트업 + 유저 제외 처리)
│   ├── 3. AI 메일 생성 (진행률 표시, 완료 건부터 순차 노출)
│   ├── 4. 메일 검수 (전문 보기 + 인라인 수정)
│   ├── 5. 발송 승인 (확인 팝업 2~3단계, 책임 고지)
│   └── 6. 발송 완료
├── [P0] 회신 인박스
│   ├── 회신만 필터링해 "먹기 좋게" 정리
│   ├── 회신 분류 (긍정/조건문의/거절/자동응답)
│   └── 회신 기반 인사이트 (제품 피드백, 메일 보강점) [P1]
├── [P1] 대시보드 — 발송/오픈/회신 지표, 캠페인 현황
├── [P2] 바이어 DB 탐색 — 양질 DB 축적 후 공개
├── [P2] 인사이트 칼럼 — 내부 데이터 기반 (외부 뉴스 크롤링 아님)
└── [보류] ANALYZE(무역뉴스·신용리포트·시장동향), 커뮤니티, AI매칭 시각화
```

**P0 = MVP 필수 / P1 = MVP 직후 / P2 = 자체 DB·데이터 축적 후 / 보류 = 로드맵 제외**

## 3. 코어 플로우 화면 정의 (디원솔루션 디자인 대상)

### 화면 1. 온보딩 — 제품 프로필 설문
- 입력: 회사명, 산업, 주력 제품(스펙), 보유 인증(IATF/CE/KC 등), MOQ, 타겟 시장, 기존 수출 경험
- 근거: "AI가 마음대로 우리 회사 분석하게 두면 안 되잖아요 → 설문이 필요" (미팅)
- 형태: 스텝 위저드 3~4단계, 저장 후 수정 가능

### 화면 2. 타겟 필터링 & 리스트업
- 필터: 산업 카테고리 / 국가·지역 / 기업 규모 / (인증 요구 여부)
- 결과: 발송 후보 리스트 테이블 — 기업명, 국가, **1줄 요약**, 컨택 포인트 유무
- 액션: 체크박스로 제외 처리 → "N개사에 발송 리스트 확정"
- 금지: 기업 상세 페이지로 깊이 들어가는 뎁스 (요약 툴팁/확장 행 정도만)

### 화면 3. AI 메일 생성 (진행 화면)
- "AI가 메일을 작성하고 있습니다" 진행률 + 완료 건부터 리스트에 순차 표시
- 각 행: 수신 기업, 제목 미리보기, 상태(생성중/완료/실패)

### 화면 4. 메일 검수·수정
- 리스트 + 우측 전문 패널 (또는 모달)
- 전문 인라인 수정 가능, 수정본 저장
- 일괄 승인 / 개별 승인

### 화면 5. 발송 승인 (책임 소재 플로우)
- 팝업 1: "작성된 메일 전문을 모두 확인하셨습니까?"
- 팝업 2: "발송 후 취소할 수 없습니다. AI 작성 내용에 대한 최종 검수 책임은 사용자에게 있습니다."
- 팝업 3(최종): "N개사에 진짜 발송합니다. 확실하신가요?"
- ※ 편의성 트레이드오프는 디자인 단계에서 조정 (미팅 합의: 2~3회 선)

### 화면 6. 회신 인박스
- 회신 온 것만 리스트업 (발송함과 분리)
- 분류 태그: 긍정 / 조건 문의 / 거절 / 자동응답
- 회신 상세 + 원 발송 메일 스레드 뷰
- [P1] 회신 데이터 요약 인사이트 블록

### 화면 7. 대시보드 [P1]
- 캠페인별: 발송 수 / 회신 수 / 회신율
- 최근 회신 미리보기, 진행 중 캠페인 상태

## 4. 유저 플로우 다이어그램

```
가입 → [온보딩: 제품 프로필] → 홈(대시보드)
                                   │
                          "새 캠페인 시작"
                                   ▼
        필터 설정 → 리스트업 → 제외 처리 → 리스트 확정
                                   ▼
        AI 메일 생성(로딩) → 검수/수정 → 승인 팝업 ×3 → 발송
                                   ▼
                     회신 인박스 ← (회신 수집)
                                   ▼
                     회신 분류·평가 → [후속 대응]
```

## 5. 데이터 전제 (개발자 미팅 논의 항목)

| 항목 | 초기(MVP) | 이후 |
|---|---|---|
| 바이어 DB | 구매 리스트 ~10,000건 임포트 | Hunter.io류 API 연동, 자체 축적 |
| 컨택 포인트 | 구매 DB 내 이메일 + AI 보조 조사 | 검증 파이프라인 |
| 메일 발송 | 발송 인프라 필요 (대량 발송, 도메인 평판 관리) | 회신 수집 IMAP/웹훅 |
| AI 메일 생성 | LLM API + 제품 프로필 + 바이어 정보 프롬프트 | 회신 데이터 학습 반영 |
| 기업 정보 | 1줄 요약 (LLM 요약) | 상세는 P2 |
