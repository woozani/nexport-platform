## 1. 개요

| 항목 | 내용 |
|---|---|
| 제품명 | NEXPORT |
| 한 줄 정의 | 한국 중소 제조사를 위한 AI 바이어 아웃리치 시스템 — 필터링부터 발송·회신 관리까지 단일 플로우 |
| 포지셔닝 | 옵션 B− : "유의미한 바이어 매칭 횟수 × 매칭 정밀도" 제공 (매출 결과 보장 X) |
| 직접 경쟁 | LinkedIn Sales Navigator |
| 경쟁 기준선 | 구글링 + 엑셀 DB + 번역기 콜드메일 (아날로그 현장) |
| 반면교사 | Apollo.io — 기능 과다, 뎁스 과다 |

## 2. 타겟 유저

- **Primary Buyer:** 매출 50~200억 제조사 대표 (성장 정체 + 매몰비용 고통)
- **Champion/User:** 해외영업 담당 1~2인
- **첫 6개월 ICP:** 자동차부품 등 인증 게이트 산업 × 경기·인천·충청 × 200~300사
- **KOTRA 관계:** 보완재 (수출바우처 탈락 29/30 + 통과 후 매칭 0건 기업 + 수행기관)

## 3. 문제 정의

- 수개월 인건비를 쏟아도 콜드메일 회신율 0% 수렴 → 매몰비용 수천만원
- 원인 3층: DB 품질(죽은 연락처) + 콘텐츠 품질(번역기 영어, 핏 미스매치) + 신뢰 공백
- VOC 근거: Scott(자동차부품), Peter(수처리) `[ VOC 5건 + 정량 4종 숫자 기입 ]`

## 4. 솔루션 스코프 (MVP)

### 4-1. 포함 (P0)
1. 온보딩 — 회사·제품·인증 프로필 설문
2. 타겟 필터링 & 발송 리스트업 (제외 처리 포함)
3. AI 맞춤형 메일 생성 (제품 프로필 + 바이어 정보 기반)
4. 메일 전문 검수·수정
5. 발송 승인 플로우 (확인 팝업 2~3단계, 유저 책임 고지)
6. 대량 발송
7. 회신 인박스 (회신 분류·평가)

### 4-2. 제외 (명시적)
- DB 브라우징·시각화 전면 노출 (양질 DB 축적 후 P2)
- 커뮤니티, 외부 뉴스 크롤링(ANALYZE 뉴스/신용/시장 뷰), 체류시간용 기능
- 매출/거래 성사 보장성 기능 표현 일체

### 4-3. P1 (MVP 직후)
- 대시보드 (발송/회신 지표)
- 회신 데이터 기반 인사이트 (제품 피드백·메일 보강점)
- 뉴스레터 (마케팅 채널)
