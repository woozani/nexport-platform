## 2. 딥다이브 — 3개 그룹 분류

### 그룹 A. 대기업 제외 섹터 (BOL 발굴 무의미 — Phase 0 영구 제외)
완성차(8703), 배터리(8507), 석유(2710), 가전(8418/8450), 타이어(4011), 철강판재(72류), 강관(7304/06), 합성수지 원료(39류 프라이머리), 태양광(8541), 대형 변압기, SSD·전산기록매체.
**공통 구조:** 수출자 1~4개사 → consignee가 자사 미국법인/JV → 매칭할 "제3자 바이어"가 존재하지 않음. 물량 랭킹의 약 75%가 이 그룹.

### 그룹 B. 중소 분산 적합 (Phase 0 후보 풀)
| 후보 | 강점 | 약점 |
|---|---|---|
| 8708 자동차부품 | 물량·분산 동시 충족 유일, Jay 도메인+VOC | OEM 노이즈 필터 필수 |
| 8481 밸브 + 8413 펌프 + 7318 파스너 | **기계요소 트리오 — 실측 분산도 최상급 산업재**, 미국 산업재 유통사 consignee | 단가 낮음, 인증 게이트 약함(ICP 스토리 보강 필요) |
| 3304 화장품 | Top 10 내 유일한 추가 중소 분산 품목, MoCRA 게이트 | 스코프 밖 + Jay 도메인 외 (기각 이력) |
| 9018/9021 의료기기 | FDA 게이트·고단가·전문 유통 분산 | 절대 물량 작음, 일부 항공 운송 |
| 식품(라면·김) | consignee 분산 최상 | ICP(제조업 B2B) 정합 없음 — 제외 권고 |

### 그룹 C. 혼재 — 필터 완성 후 2차 후보
8504 중소형 전력기기, 8431 건설기계 부품, 3923/3926 플라스틱 가공품, 8536 커넥터. oem_large 필터 신뢰도가 검증된 뒤(Phase 1 이후) 확장.

## 3. 스코프 재설정 제안 (dev_spec policy 2 v1.1)

**핵심 발견:** 기존 "화학" 섹터는 원료(수지·석유화학)가 전부 대기업 지배라 BOL 발굴이 빈약하다. 반면 **기계요소류(밸브·펌프·파스너)가 실제 분산도 최상급인데 기존 3섹터 어디에도 없다.**

> **제안 스코프: ① 자동차부품(8708) ② 의료기기(9018/9021) ③ 산업 유체·기계요소(8481/8413/8421)**
> — "화학"을 "산업 유체·기계요소"로 재정의: 수처리(8421)를 포함하면서 밸브·펌프로 물량을 확보. Peter VOC(수처리)와의 연속성 유지, 인증 스토리는 API/ASME/NSF 등 산업 규격으로 성립.

Phase 0 회차 재배열: **W1 8708.30 (유지)** → 2회차 **8481 (밸브)** → 3회차 9018.90 → (선택) 4회차 3304 데이터만 검증.

## 4. 한계 고지
- 해상/항공 분리는 공개 통계 기반 추정 — 확정치는 USITC DataWeb vessel 필터 필요 (Phase 0 목적에는 불요).
- 분산도 판정은 ImportYeti 표본·산업 구조 지식 기반 정성 판정 — **Phase 0의 M1 실측이 이 표를 검증/수정하는 구조** (회차마다 본 문서 업데이트).
- 철강·알루미늄 50% 관세, 자동차부품 15% 관세 등 통상 변수는 분기 리뷰 (생존전략 F7 연동).
