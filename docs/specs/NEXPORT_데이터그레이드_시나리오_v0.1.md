**표기:** `[제안값]` = Jay 검토 후 확정 필요한 수치. 로직 구조 자체는 확정 제안.

## 1. 설계 원칙 (8/13 회의 합의 기반)

1. **MVP의 목적은 매출이 아니라 데이터 검증** — 유효 데이터와 죽은 데이터를 나누는 것
2. Free tier 유저 = 데이터 검증 엔진. 이들의 발송·반응이 곧 라벨링 작업
3. 검증된 상단(골드) 데이터가 본 버전의 유료 상품
4. 데이터는 소모품 — 걸러질수록 신규 유입 필요 (지속 구매 파이프라인 전제)

## 2. 바이어 데이터 등급 체계

| 등급 | 정의 | 진입 조건 | 노출 대상 |
|---|---|---|---|
| **GOLD** | 반응 검증 완료 | 회신 1회 이상 발생 이력 | Premium 추천 우선 배정 |
| **SILVER** | 관심 신호 있음 | 열람 `[제안값: 2회]` 이상 or 첨부 열람 1회 | Standard 이상 추천 |
| **BRONZE** | 미검증 (신규) | 데이터 입수 직후 기본값 | 전체 tier 추천 풀 (Free 포함) |
| **COLD** | 반응 저조 | 매칭 `[제안값: 3회]` 소진, 무반응 | 추천 제외, 재활성 조건 대기 |
| **DEAD** | 폐기 | 매칭 `[제안값: 5회]` 전부 무반응 or 반송(bounce) `[제안값: 2회]` | 영구 제외 |

### 등급 이동 이벤트
```
BRONZE ─열람 발생─→ SILVER ─회신 발생─→ GOLD
BRONZE ─매칭 3회 무반응─→ COLD ─매칭 5회 누적 무반응─→ DEAD
COLD ─[제안값: 6개월] 경과─→ BRONZE 복귀 (담당자 이직 등 상황 변화 가능성)
GOLD/SILVER ─최근 [제안값: 12개월] 무반응─→ 한 등급 강등
* bounce(반송) 발생: 즉시 이메일 무효 플래그, 2회 누적 시 DEAD
* 스팸 필터 강제 로드 위양성 대응: '열람'은 로드 후 [제안값: 5초] 이상 or 2회 이상 로드 시에만 인정 — 기술 검토 요청
```

## 3. 스코어링 (등급 내 정렬용)

바이어별 engagement score = 최근 `[제안값: 6개월]` 이벤트 가중 합산:

| 이벤트 | 점수 |
|---|---|
| 회신 | +10 |
| 첨부(카탈로그) 열람 | +5 |
| 본문 열람 | +1 |
| 오프-플랫폼 진행 체크 (영업보고서 유저 입력: 별도 메일/미팅/샘플) | +15 |
| 발송 대비 무반응 (발송 후 2주 경과) | -2 |
| 반송 | -10 |

- 추천 배정 시 동일 등급 내에서는 score 상위부터
- **카테고리 연관성 필터가 score보다 선행** — 유사도 미달 바이어는 score 무관하게 추천 안 됨 (읽음 수집용 스팸 발송 유인 차단)

## 4. 매칭 락(독점) & 해제 규칙

### 4-1. 기본 규칙
- 바이어 1명 : 유저 1명 독점 매칭 (동시 다중 배정 금지 — 같은 바이어에게 한국 업체 여럿이 동시 콜드메일 가면 데이터·평판 모두 훼손)

### 4-2. 해제(unlock) 조건 — 이 중 하나라도 충족 시
| 조건 | 기간/기준 | 근거 |
|---|---|---|
| 발송 후 무반응 | `[제안값: 2주]` (2차 발송 포함 총 2회 발송 기준) | 회의 중 예시 합의. 해외영업 실무상 콜드메일 반응은 대부분 1주 내, 2주면 관심 없음 판정 가능 |
| 유저가 [제외] 클릭 | 즉시 | 유저 스스로 부적합 판정 |
| 유저 미발송 방치 | 추천 후 `[제안값: 4주]` 발송 안 함 | 슬롯 낭비 방지 |
| 유저 구독 해지 | 해지일 + `[제안값: 2주]` 유예 | 진행 중 거래 보호 |

### 4-3. 락 유지 조건 (해제 예외)
- 회신 발생 → 마지막 상호작용으로부터 `[제안값: 3개월]` 락 유지
- 영업보고서에서 오프-플랫폼 진행 체크 → 체크 시점부터 `[제안값: 3개월]` 연장, 매월 보고서에서 재확인
- 거래 단계(미팅/샘플/견적/계약) 입력 → 계약 완료 또는 유저가 종료 선언까지 무기한 유지
- **오프-플랫폼 체크가 있는데 갱신이 없는 경우:** `[제안값: 2개월]` 무갱신 시 "진행 중인가요?" 확인 요청 1회 → 무응답 `[제안값: 2주]` 후 해제

### 4-4. 해제 후 처리
- 바이어는 등급 재산정 후 추천 풀 복귀 (무반응이었다면 매칭 카운트 +1 누적)
- 동일 유저에게 동일 바이어 재추천 금지 기간: `[제안값: 6개월]`

## 5. Free Tier 검증 엔진 운영 규칙

- MVP 기간 Free 정책: 월 `[제안값: 3~5건]` 추천 + 발송 + 기본 트래킹 제공 (보고서 PDF는 유료 `[Jay 확정 필요]`)
- 초기 `[제안값: 3개월]`은 전원 무료 — 목적: 발송량 최대화로 BRONZE 데이터 라벨링 가속
- 발송량 확보 장치: 추천 수령 후 미발송 유저에게 리마인드 `[제안값: 1주 후 1회]`
- 남용 방지: 동일 유저 월 발송 상한 (tier별 추천 건수 = 발송 상한, 별도 대량 발송 기능 없음)

## 6. 데이터 파이프라인 요구사항

- 신규 데이터 유입 주기: `[제안값: 분기별]` 추가 구매 (DEAD 비율이 `[제안값: 20%]` 도달 시 조기 구매 트리거)
- 입수 시 전처리: ① 이메일 verify 상태 확인 ② AI 한 줄 요약 생성 (배치) ③ 키워드 임베딩 생성 ④ BRONZE 등급 부여
- 관리자 페이지 모니터링 지표:
  1. 등급별 재고 분포 (GOLD/SILVER/BRONZE 잔량)
  2. 카테고리별 회신율 (어떤 분야가 돈이 되는지)
  3. 유저 검색·제외 사유 로그 (카테고리/데이터 확장 우선순위)
  4. DEAD 전환율 (구매 데이터 품질 평가 → 벤더 교체 판단)
