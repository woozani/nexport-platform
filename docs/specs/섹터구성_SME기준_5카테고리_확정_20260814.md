## 1. 핵심 인사이트 (Jay 제공 — 검토 완료)

- **화장품이 압도적으로 SME 친화적** — 전체 화장품 수출의 상당 비중(약 60~70%, 중기부 기준 중소기업 수출 1위 품목)을 중소기업이 담당 + 미국이 최대 성장 시장(대중국 추월)
- **플라스틱 제품**이 그 다음으로 SME 수출 실적이 좋고, 거래 건수도 상대적으로 많음 (중소기업 수출 상위 2~3위 품목)
- **자동차는 금액은 크지만 대기업 + OEM 비중이 너무 높아 Phase 0 부적합** (Aftermarket만 분리하면 일부 가능)
- **기계류 대형 설비, 반도체, 완성차는 제외**

### 검토 주석 (Claude 검증, 2026-08-14)
1. 화장품 SME 비중·대미 성장은 공개 통계와 부합. 외부 문서 인용 시 "약 2/3 수준(60~70%)" 표기 권장.
2. **3926.90은 필터 전제 조건부** — 월 수입 $7억 규모로 범주가 넓어 하위 세분(3926.90.99 등)·키워드 필터 없이 쓰면 노이즈 극대 (Top20 딥다이브 판정). 채택하되 Phase 0 정제 단계에서 품목 키워드 필터를 함께 검증할 것.
3. 자동차부품 탈락으로 **Jay 도메인 우위·Scott VOC 자산은 Phase 0에서 미사용** — 단 화장품·플라스틱·접착제도 "인증·규격 게이트"(MoCRA, FDA 등록, UL/ASTM) 스토리가 성립하므로 벙커샷 ICP 논리는 유지 가능. 자동차 애프터마켓(8708.30)은 확장 후보 풀에 보존.
