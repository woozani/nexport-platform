# NEXPORT 고객 여정 기획서 v0.2
**작성:** 2026-08-13 회의 반영 / 디원솔루션 전달용
**변경 핵심 (v0.1 대비):** 검색·리스트 브라우징 모델 폐기 → **월 N건 자동 추천(큐레이션) 모델**로 전환. 타겟 입력은 서술형(주관식) 우선.
**요구 수준:** 60~70% 완성도. 플로우의 명확성 우선. 세부 수치 중 `[제안값]` 표기는 확정 전 제안.

---

## 0. 전체 플로우 한 장 요약

```
랜딩 → 회원가입 → 회사 프로필 작성(서술형) → [가입 훅: 유사 바이어 5개 미리보기]
  → 월간 추천 바이어 수신 (요금제별 N건) → 바이어 카드 확인(연락처 비노출, AI 한줄요약)
  → 발송 승인/제외 → AI 메일 초안 → 수정 → 플랫폼 내 발송
  → 트래킹 (리소스 삽입) → 대시보드 상태 확인
  → [무반응 D일] 2차 발송 알림 → [무반응 W주] 매칭 해제·재매칭
  → 월간 영업 보고서 자동 생성 (오프-플랫폼 활동 체크 포함) → PDF 출력
  → (거래 진전 시) 거래 상태 업데이트 → 수수료 프로세스
```

---

## 화면 1. 랜딩 페이지
- 구성: 문제 공감 → 해결 3단계 → 차별화 1개 → CTA
- CTA 버튼: **[무료로 내 바이어 확인하기]** → 회원가입으로 이동
- 상세 카피는 홈페이지 개편안에서 별도 전달

## 화면 2. 회원가입
- 입력: 이메일, 비밀번호, 회사명, 사업자등록번호, 담당자명/직책
- 버튼: [가입하기] → 화면 3으로 이동
- 소셜/간편가입: MVP 제외

## 화면 3. 회사 프로필 작성 (매칭의 입력값) ★핵심 화면
- **3-1. 서술형 입력 (주력):**
  - 질문 예시: "어떤 제품을 만들고, 어떤 바이어를 찾고 계신가요? 자유롭게 적어주세요."
  - placeholder 예: "산업용 정수처리 필터를 제조합니다. 미국의 수처리 설비 업체나 유통사를 찾고 있습니다."
- **3-2. 구조 입력 (보조):**
  - 타겟 국가 (MVP: 미국 단일 → 선택 UI만 준비)
  - 산업 대분류 선택 — Apollo 대분류 그대로, **최후의 보루** 역할
  - 보유 인증 체크박스: FDA / CE / ISO 13485 / IATF 16949 / 기타 직접입력
  - HS코드 (선택, 자동 추천 있으면 좋음 — 우선순위 낮음)
- 버튼: [프로필 저장하고 내 바이어 보기] → 화면 4

## 화면 4. 가입 훅 — 유사 바이어 미리보기 (8/13 회의 개발자 제안 반영)
- 프로필 서술 기반 AI 매칭 → **유사 바이어 5개를 한 줄 요약으로 노출**
  - 예: "캘리포니아 소재 수처리 설비 유통사 · 직원 50~200명"
  - 회사명·연락처 **비노출** (마스킹)
- [새로고침] 버튼: 다른 5개 재추천 (호출 제한 `[제안값: 3회]`)
- 목적: 가입 직후 "여기 진짜 내 바이어가 있다" 증명 → 유료 전환 동기
- 버튼: [이 바이어들에게 메일 보내기 시작] → 화면 5 (대시보드)

## 화면 5. 대시보드 (메인)
- 상단: 이번 달 추천 바이어 `n/N건` / 발송 `n건` / 열람 `n건` / 회신 `n건`
- 중앙: **이번 달 추천 바이어 카드 리스트** (화면 6의 진입점)
- 좌측 메뉴: 대시보드 / 추천 바이어 / 발송 현황 / 영업 보고서 / 마이페이지(프로필·요금제)
- ※ 전체 바이어 리스트 검색·브라우징 화면은 **존재하지 않음** (스크래핑 방지 정책)

## 화면 6. 추천 바이어 카드 ★핵심 화면
- 매월 요금제별 N건 자동 추천 (배치 갱신일: 매월 1일 `[제안값]`)
  - Free: 월 `[제안값: 3건]` / Standard: 월 `[제안값: 10건]` / Premium: 월 `[제안값: 20건 + 골드 등급 위주]`
- 카드 노출 정보:
  - AI 한 줄 요약 (Apollo 키워드를 정제한 문장 — raw 키워드 비노출)
  - 국가/주, 산업 분야, 직원 수 규모, 매칭 근거 (예: "수처리 관련 키워드 유사도 + FDA 등록 수입업체")
  - **회사명 부분 마스킹, 이메일·연락처 완전 비노출**
- 카드별 버튼: [메일 보내기] → 화면 7 / [제외] → 사유 선택 (분야 안 맞음/규모 안 맞음/기타) → 제외 데이터는 관리자 페이지로 수집
- 제외 시 보충 추천: 제외한 만큼 신규 추천 충전 여부 `[Jay 확정 필요 — 제안: 월 2건 한도 내 충전]`

## 화면 7. AI 메일 작성
- 자동 생성: 내 프로필 + 바이어 정보 기반 영문 콜드메일 초안
- 편집: 제목/본문 직접 수정 가능, [AI 다시 쓰기] 버튼 (톤 옵션: 격식/간결 `[후순위]`)
- 첨부: 카탈로그 등 파일 첨부 (열람 트래킹 대상)
- 버튼: [발송] — 플랫폼 내부 발송 (외부 메일앱 연동 없음, 트래킹 목적)
- 발송 전 확인 모달: "발송 후 회수 불가" 안내

## 화면 8. 발송 현황 / 트래킹
- 바이어별 타임라인: 발송됨 → 열람됨(리소스 로드 기준) → 첨부 열람 → 회신됨
- 상태 뱃지: 무반응 `D일[제안값: 7일]` 경과 시 "팔로업 추천" 표시 → [2차 메일 보내기]
- 무반응 `W주[제안값: 2주]` 경과 시: "매칭 해제 예정" 안내 → 자동 해제 후 해당 슬롯에 신규 추천 충전
- 회신 수신: 플랫폼 내 수신함에서 확인 (MVP 범위 — 회신 열람까지, 스레드 대화는 후순위)

## 화면 9. 영업 보고서 (월간 자동 생성) ★리텐션 장치
- 자동 생성 주기: 월 1회 `[+주간 요약은 후순위]`
- 자동 포함 내용: 기간 내 추천/발송/열람/회신 건수 funnel, 바이어별 상태 표, 날짜
- **유저 편집 필드 (오프-플랫폼 활동 회수 장치):**
  - 체크박스: [별도 이메일 진행 중] [카탈로그/견적 발송함] [샘플 논의] [화상미팅 진행] [전화 통화]
  - 자유 서술 메모란
  - → 이 체크 데이터가 매칭 락 유지 판단 + 데이터 그레이딩의 입력값이 됨
- 버튼: [PDF 다운로드] — 상사 보고용. 바이어 연락처는 보고서에도 비노출, 회사명은 노출 `[Jay 확정 필요]`

## 화면 10. 거래 상태 업데이트 (수수료 연결)
- 보고서 체크 필드에서 [샘플 논의] 이상 진행 시: "거래 단계를 업데이트해주세요" 유도
- 단계: 미팅 → 샘플 → 견적 → 계약
- 계약 단계 입력 시 수수료 프로세스 안내 `[수수료 인식 시점·증빙 방식은 별도 정책 문서로 확정 예정 — 미결]`

## 마이페이지
- 프로필 수정 (수정 시 추천 재계산은 다음 배치부터 `[제안값]`)
- 요금제 관리 / 결제
- 알림 설정 (이메일 알림: 회신 수신 시, 보고서 생성 시)

## 미결 사항 (디원솔루션과 논의 필요)
1. 추천 배치 방식: 월 1회 일괄 vs 주 단위 분할 지급 — 개발 공수 차이 의견 요청
2. 제외 사유 데이터의 관리자 페이지 수집 스키마
3. 회신 메일 수신 구조 (플랫폼 수신함 vs 포워딩) 기술 검토
4. 스팸 필터 리소스 강제 로드 위양성 — 실발송 테스트 계획 수립
5. AI 한 줄 요약 생성 시점: 데이터 입수 시 일괄 배치 vs 추천 시점 실시간 — 비용 구조 의견 요청
